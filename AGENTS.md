# TouchValidator website

The app owner has explicitly stated that TouchValidator is proprietary and its source code must remain private.

Only presentation assets, installation binaries and download checksums belong in `dist/`. Never package, upload or link Android/iOS app source archives, app source trees, credentials or device logs from this website. Do not advertise the app as open source. The website's HTML, CSS and JavaScript are separate from the private app source.

Run `node scripts/verify-release.mjs` before packaging or publishing. Keep the original app repositories and their existing licensing files unchanged when editing this website.
